Harness² Execution Integration Level

Strict Snapshot Isolation During Candidate Probes

              
Guarantees that during a comparison of K candidate harnesses, later candidates cannot read notes written during earlier candidates' execution.

            

            
          


          

            

              
Default Recursion Mode & Candidate Count (K)

              
Parallel explores K candidates concurrently in branched workspaces; Sequential refines through K steps.

            

            

              
              
            

          


          

            

              
Reasoning Depth & Token Efficiency Profile

              
Controls thinking token depth, Cue-First RAG snippet pruning, and subagent model routing so Harness² loops stay fast and token-efficient.

            

            
          


          

            

              
Max Thinking Token Budget & Candidate Prober Model Tier

              
Caps thinking tokens per probe turn (e.g. 2048) and routes candidate probers to lighter models (flash / flash_lite) while keeping your main agent on its primary model.

            

            

              
              
            

          


          

            

              
Cue-First RAG Snippet Cap & Early-Stop Token Guardrail

              
Truncates retrieved RAG snippets to compact cues (default 500 chars) and stops sequential probing early once a candidate passes 100% of verification checks.
